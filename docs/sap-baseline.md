# SAP 标准卡基准：BOM 不可信时怎么做差异

## 1. 什么时候用

第二层复算跑通后，常见两种局面：

| 局面 | 做法 |
|---|---|
| BOM/工艺路线与 ERP 标准卡一致 | 用 BOM 卷算，做六项差异 |
| BOM 只到关键件、工时定额失真，但 ERP 有标准成本卡 | **用本文的 SAP 标准卡基准** |

汽车零部件样例就是第二种：BOM+工艺卷算 286.26 元/件，SAP 标准卡 456.93 元/件，
差 37%；标准工时 0.125h/件，实际 1.423h/件，差 11 倍。此时用 BOM 做基准，
会把「标准不对」误判成「车间节约/超支」。

## 2. 方法

1. 从 SAP CK13n 读四个成本组件：材料、人工、费用、外协；
2. 用 **18 个月综合均值** 作为单件标准（也可换成 2025 或 2026H1 列）；
3. 分项四舍五入尾差并入材料，保证四项之和等于合计；
4. 标准金额 = 单件标准 ×（完工数量 + 废品数量），与 ERP 单位成本的分母一致；
5. 实际金额来自第二层复算：材料/人工/费用；外协无单独实际数，按 0 列示并注明；
6. 逐项算差异额、差异率，并判断是否「系统性同向偏差」。

## 3. 系统性偏差判据

四项差异率**同号**且绝对值都 ≥10%，判为系统性偏差：

```text
材料 -18.16% / 人工 -35.02% / 费用 -37.46% / 外协 -100.00%
```

含义：不是某一个部门做得好或差，而是基准与本期口径不一致。常见原因：

- 标准卡是年度版本，本期工艺/采购价已变；
- 标准卡含未纳入本次导出的成本项（如外协、质量成本）；
- 产量口径不同（标准按计划量、实际按完工量）；
- 标准卡是集团口径，工厂口径不同。

## 4. 输出示例

```text
SAP 标准卡基准 · 2026-06
基准：SAP CK13n 18 个月均值 456.93 元/件 × 5,128 件（完工+废品）

项目              实际          标准         差异    差异率
材料      1,153,696.40  1,409,738.48  -256,042.08   -18.16%
人工        293,700.20    451,981.92  -158,281.72   -35.02%
费用        265,900.00    425,162.48  -159,262.48   -37.46%
外协              0.00     56,254.16   -56,254.16  -100.00%
合计      1,713,296.60  2,343,137.04  -629,840.44   -26.88%
单位成本        334.11        456.93      -122.82   -26.88%
```

## 5. 能下与不能下的结论

**能下：**

- 实际单位成本 334.11，比标准低 26.88%；
- 材料（含外协）低 21.30%，人工低 35.02%，费用低 37.46%；
- 四项同向，属于系统性偏差，不是单项绩效。

**不能下：**

- 不能把差额归责到采购或车间；
- 不能拆分价差/量差（标准卡只有金额，没有数量与单价）；
- 不能直接说「全面降本」——真实绩效差异很少四项同向且幅度如此整齐；
- 外协实际数为 0，不代表没有外协，可能已包含在半成品结转价里。

## 6. 边界

- 标准卡只有金额，所以只能做四要素金额差异，不能做六项价量差；
- 不含废品损失：ERP 单位成本含废品损失，本表分母用完工+废品，口径已在报告注明；
- 不含在产：与 ERP 单位成本口径一致，在产成本另由第二层复算给出；
- 标准卡期间与本期不同时，结论只能用于「量级判断」，不能用于考核。

## 7. 扩展

- 若拿到实际外协结算单，可把外协从材料中拆出，单独做差异；
- 若标准卡有分项数量/单价，可升级为价差/量差；
- 若有多期标准卡，可做「标准版本迁移」对账，定位标准变更的影响。
