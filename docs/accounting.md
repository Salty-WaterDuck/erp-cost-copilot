# 记账与结账

成本模块和总账的接口，只有一句话：**每一分钱的去向都要能被科目解释**。

这份文档说明科目怎么设、凭证怎么生成、试算怎么平、结账为什么会被拦住。

---

## 1. 边界

本模块只负责「成本相关」的凭证，不做完整总账：

- 不管销售收入、应收应付、税金、固定资产购置；
- 不管期末损益结转（本年利润）；
- 期初余额由外部总账导入（示例数据里给了最小的一套）。

这样切的原因是：作品集要证明的是**成本核算能落地到账务**，而不是重写一个金蝶。

## 3. 凭证规则

| 业务 | 借方 | 贷方 | 金额来源 |
|---|---|---|---|
| 材料领用 | 5001 生产成本 | 1403 原材料 / 1406 自制半成品 | 领料单金额（半成品用实际结转价） |
| 直接人工 | 5001 生产成本 | 2211 应付职工薪酬 | 报工工时 × 费率 |
| 制造费用发生 | 5101 制造费用 | 1002 / 1602 / 2211 | 按费用类型映射资金来源 |
| 制造费用分配 | 5001 生产成本 | 5101 制造费用 | 动因分配结果 |
| 完工入库 | 1405 库存商品 / 1406 自制半成品 | 5001 生产成本 | 完工入库成本 |
| 未分配费用结转 | 6602 管理费用 | 5101 制造费用 | 结账时的余额 |

费用类型到资金来源的映射在 `accounts.EXPENSE_ACCOUNT`：

```text
水电费 / 辅料耗材 / 维修备件 / 外委维修 → 1002 银行存款
设备折旧 / 检测设备折旧               → 1602 累计折旧
车间管理薪酬                          → 2211 应付职工薪酬
```

### 一张真实的凭证

```text
2026-10-003  2026-10-31  PO-1003 材料领用
  借  5001 生产成本        20,061.86  PO-1003 领料
  贷  1403 原材料           2,632.50  PO-1003 原材料
  贷  1406 自制半成品      17,429.36  PO-1003 半成品转入
```

成品的材料成本里，半成品按**本期实际完工成本**结转（壶身 20.9034、底座 17.8285），所以上游工单的超支会顺着 BOM 进入这张凭证，而不是被标准价抹平。

## 4. 试算平衡

```text
期末余额 = 期初余额 + 本期借方 − 本期贷方
借方余额为正，贷方余额为负
```

演示数据结账后的试算表：

| 科目 | 名称 | 期初 | 借方发生 | 贷方发生 | 期末 |
|---|---|---:|---:|---:|---:|
| 1002 | 银行存款 | 借 500,000.00 | 0.00 | 2,400.00 | 借 497,600.00 |
| 1403 | 原材料 | 借 80,000.00 | 0.00 | 26,787.40 | 借 53,212.60 |
| 1405 | 库存商品 | 借 120,000.00 | 30,879.15 | 0.00 | 借 150,879.15 |
| 1406 | 自制半成品 | 借 5,000.00 | 26,829.52 | 25,175.74 | 借 6,653.78 |
| 1602 | 累计折旧 | 贷 60,000.00 | 0.00 | 1,380.00 | 贷 61,380.00 |
| 2211 | 应付职工薪酬 | 贷 30,000.00 | 0.00 | 4,571.00 | 贷 34,571.00 |
| 4001 | 实收资本 | 贷 615,000.00 | 0.00 | 0.00 | 贷 615,000.00 |
| 5001 | 生产成本 | 0.00 | 60,054.14 | 57,708.67 | 借 2,345.47 |
| 5101 | 制造费用 | 0.00 | 4,480.00 | 4,480.00 | 0.00 |
| 6602 | 管理费用 | 0.00 | 260.00 | 0.00 | 借 260.00 |
| **合计** | | | **122,502.81** | **122,502.81** | **0.00** |

三个可以自证的地方：

1. 本期借方合计 = 贷方合计 = 122,502.81；
2. 期末余额合计 = 0（会计恒等式成立）；
3. `5001` 期末余额 2,345.47 = 两张未完工工单的在产品成本之和。

第 3 条最关键：它说明成本计算单和总账是同一套数，而不是两张皮。

## 5. 期末结账

结账检查项：

| 检查 | 阻断 | 逻辑 |
|---|---|---|
| `LEDGER-BALANCED` | 是 | 每张凭证借贷相等，全账借贷相等 |
| `OPENING-BALANCED` | 是 | 期初余额借贷平衡 |
| `COST-CONSERVATION` | 是 | `5001` 余额 = Σ 工单期末在产 |
| `TRIAL-BALANCE` | 是 | 期末余额合计为 0 |
| `OH-UNALLOCATED` | 模式相关 | 未分配制造费用的处理 |
| `WIP-CARRIED` | 否 | 提示期末在产金额 |
| `SCRAP-RATE` | 否 | 综合报废率超容差时预警 |

### 未分配制造费用的两种态度

| 模式 | 行为 |
|---|---|
| 默认 | 自动生成凭证：借 6602 管理费用 / 贷 5101 制造费用，结账通过，清单里留痕 |
| `--strict` | 直接阻断：费用没分完就不许关账，必须回退去补动因或调整分配 |

两种都合理。默认模式贴近实务（小额未分配费用月末转期间费用），严格模式贴近管理诉求（费用必须找到承担对象）。做成开关，而不是写死。

### 结账输出

```text
[提示·允许] LEDGER-BALANCED: 凭证借贷平衡，合计 122242.81
[提示·允许] OPENING-BALANCED: 期初余额平衡，借方合计 705000.00
[警告·允许] OH-UNALLOCATED: 未分配制造费用 260.00 已转管理费用（凭证 2026-10-018）
[提示·允许] WIP-CARRIED: 期末在产品成本 2345.47，保留在生产成本科目
[提示·允许] COST-CONSERVATION: 生产成本余额 2345.47 = 期末在产 2345.47
[提示·允许] TRIAL-BALANCE: 试算平衡：期末余额借贷合计相等
结论：可以结账
```

## 6. 可追溯

每条凭证都带业务摘要（工单号 + 业务类型），可以反查：

```text
凭证 2026-10-003 → 工单 PO-1003 → 领料单 MI-1008/1009/1010/1011 → 成本计算单 PO-1003
```

成本计算单的每一行也能说明自己进了哪张凭证。这是「控制」的前提：数字能被质疑，也能被解释。

## 7. 取舍

**为什么 5001 不设明细科目？**

如果按材料/人工/费用设 `500101/500102/500103`，完工结转时贷方就要在三个明细里分摊，分摊口径又成了一个需要解释的问题。实务里成本项目是通过「成本计算单 + 工单」管理的，总账只保留一个总数。本项目选择让总账简单、让成本单详细。

**为什么累计折旧是贷方余额的资产科目？**

它是备抵科目，减少固定资产净值。把它单独列出，是为了让「折旧不减少银行存款」这件事在试算表里一眼可见。

**为什么凭证日期统一取期末？**

本期单据可能分散在整月，但成本计算是月末一次完成的。真实系统会按业务日期记账，这里统一取期末，避免出现「成本凭证早于领料单」的时间倒挂。
