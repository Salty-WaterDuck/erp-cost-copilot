# 报表级成本体检：只有汇总表时能做什么

真实项目里，成本会计手里常常没有完整的 BOM、领料单、报工单，只有几张从 ERP 导出的汇总报表。这一层就是为这种场景准备的：**不重算成本，只做趋势、异常和跨表勾稽。**

## 1. 两种数据层级

| 层级 | 数据 | 能做什么 | 不能做什么 |
|---|---|---|---|
| 单据级 | BOM、领料、报工、费用、标准成本 | 归集、分配、约当产量、六项差异、凭证 | — |
| 报表级 | 成本计算单、成本构成、存货明细、还原表、完工日报 | 趋势、结构、异常、跨表勾稽、口径冲突 | 拆不出价差/量差，无法重算 |

报表级体检的定位：**先确认差异本身可信，再谈责任归因。**

## 2. 输入

`data/auto_reports/` 下是汽车零部件（制动卡钳总成）的 9 张样例导出：

| 文件 | 内容 | 粒度 |
|---|---|---|
| `01_sap_ck13n_成本构成分解.csv` | 材料/人工/制造费用/外协占比 | 2025 均值 / 2026H1 |
| `02_sap_存货明细.csv` | 原材料/半成品/产成品余额与差异 | 季度采样 |
| `03_kingdee_成本计算单.csv` | 工单成本、废品损失、单位成本 | 工单（18 个月） |
| `04_kingdee_成本还原汇总.csv` | 还原前/半成品还原/还原后 | 汇总 |
| `05_yonyou_完工产品日报.csv` | 完工、废品、净产量、工时、三项成本 | 月（18 个月） |
| `06_yonyou_废品回收表.csv` | 废品重量、回收单价、回收额 | 季 |
| `07_bom_物料清单.csv` | 三层 BOM（总成/半成品/原材料） | 物料 |
| `08_领料明细_月度汇总.csv` | 按工单的原材料/半成品领用 | 工单·月（汇总码） |
| `09_报工明细_月度汇总.csv` | 按工单/工序/成本中心的工时与人工 | 工单·工序·月 |

运行：

```bash
python -m costcontrol.cli --check-export data/auto_reports   # 先看能做什么
python -m costcontrol.cli --reports data/auto_reports        # 再做体检
```

## 3. 五类检查

### 3.1 结构与趋势

- 单位成本同比、成本组件涨幅排序；
- 样例：2026H1 单位成本 469.2 vs 2025 年均 450.8（+4.08%），制造费用 +6.46% 最快。

### 3.2 工单异常（均值 + 标准差）

- 对 18 期单位成本算均值与标准差，偏离 ≥2σ 的工单列为异常；
- 样例：2025-08 单位成本 359.96（+2.56σ），同月报废率 4.57%、废品损失 3.28 万；
- 返工单不一定异常：2025-10 返工单位成本 355.0，只比均值高 1.3%，不单独报。

### 3.3 报表内部勾稽

- 成本单：`(材料+人工+费用+废品损失)/完工数量` 是否等于表列单位成本；
- 样例：18/18 一致（0.02 元以内），说明这版单位成本是实际成本。

### 3.4 跨表勾稽

- 领料金额 vs 成本单材料、人工成本 vs 成本单人工、废品回收 vs 日报；
- 样例：18/18、18/18、6/6 全部一致；
- 成本还原：还原前 2,335.4 万 = 还原后 2,335.4 万（只重分类，不改变总额）；
- 存货：18 行里 1 行差 0.10 万（四舍五入级），标「低」。

### 3.5 口径与粒度

- BOM 叶子物料 vs 领料编码：0/7 覆盖——领料是 `RM-MIX-01` / `SF-MIX-01` 汇总码；
- 这直接导致材料六项差异不可用（见覆盖率检查）；
- 用友日报按「净产量」算单位成本，金蝶按「完工数量」算，跨表比较必须先统一分母。

## 5. 边界

- 不能替代单据级差异分析：没有领料明细（或只有汇总码），就拆不出价差/量差；
- 不能判断业务真实性：报表说返工，只能提示去查返工单，不能证明原因；
- 归因结论必须标注「报表级」，避免被当成单据级结论使用。

## 6. 扩展

新增一种报表只需要：

1. 在 `costcontrol/reports.py` 里加一个 dataclass 与 loader；
2. 在 `analyze()` 里加一条检查；
3. 在 `render_analysis()` 里加一段表格。

不需要动成本引擎，也不需要新的依赖。
